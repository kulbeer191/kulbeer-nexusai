Overview

Teams lose context every time work moves between a chat tool, a task tracker and a doc. Dart is an AI-native project-management workspace where AI agents work alongside people in the same board, instead of living in separate chat windows — a lead agent breaks a goal into a plan, coordinates specialist agents, and every handoff and result stays attached to the work. Small US product and engineering teams can run sprints, roadmaps and reports without a dedicated project manager.

Official site: https://www.dartai.com

Key Features

The capabilities that matter most for US teams:

  • AI agents work inside the project board next to teammates
  • Lead agent turns a goal into a plan and coordinates specialist agents
  • Connect Codex, Claude Code, Cursor, Manus, OpenClaw and GitHub Copilot as agents
  • List, board, roadmap and calendar layouts, sprints, time tracking, dependencies
  • Chat mode, Build mode, MCP server, API, CLI and webhooks

✅ Pros

  • Real free plan for up to 4 teammates — unlimited tasks, docs, storage and AI model usage, with AI agents included (unusually generous)
  • Agent directory: build agents in Dart or connect Codex, Claude Code, Cursor, Manus, OpenClaw and GitHub Copilot as agents and assign them tasks next to teammates
  • Multi-agent orchestration: a lead agent turns a goal into a plan and coordinates specialist agents that research, design, build and review in parallel or sequence
  • Full project-management feature set: list, board, roadmap and calendar layouts, sprints, time tracking, subtasks, blockers, dependencies, custom task types
  • Natural-language input, Chat mode (plan with an agent) and Build mode (execute from a linked task), plus MCP server, API, CLI and webhooks

❌ Cons

  • Free plan stops hard at 4 teammates — a 5-person team must pay for every seat
  • Slack, Discord and GitHub integrations, custom statuses/properties and forms only start on Premium; SAML SSO, SCIM, public views and analytics only on Business
  • Monthly-billing prices are NOT published on the official pricing page — only yearly rates are shown, so month-to-month budgeting is guesswork
  • The agent-centric model needs more setup than a simple task list — overkill for a team that just wants a to-do board

Frequently asked questions

Is Dart free?

Yes, for small teams. The Personal plan costs $0 for up to 4 teammates with unlimited tasks, docs and storage — and AI agents are included. Paid plans start at Premium, $8 a teammate a month billed yearly.

What is Dart best for?

Small product and engineering teams that want AI agents working inside their project tracker rather than in a separate chat window — a team assigning coding agents (Codex, Claude Code, Cursor) real tasks in the same board where humans track work, or a startup running sprints and roadmaps with AI-generated subtasks and reports.

What should I watch out for with Dart?

The free plan stops hard at 4 teammates — a 5-person team must pay for every seat. And monthly prices are not published, so check the billing toggle before budgeting.

Verdict

Best for: Small product and engineering teams that want AI agents working inside their project tracker rather than in a separate chat window — with the warning that the free plan stops at 4 teammates and monthly prices are not published.
