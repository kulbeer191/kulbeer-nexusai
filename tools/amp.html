Overview

Coding agents stop when you close your laptop, and their work dies with the session. Amp is a coding agent and development environment that gives every agent thread its own cloud machine — an “orb” — so agents keep building, testing and fixing in the background after you close your laptop. It turns the IDE into a fleet: you fire off work from the web, terminal or phone, review live through portals, and let orbs wake on outside events like a new Linear issue or a failing CI run.

Official site: https://ampcode.com/

Key Features

The capabilities that matter most for US teams:

  • Orbs — each thread runs on its own remote machine with live portals (run the app, preview changes, comment on the page to send fixes) — true async, parallel agent work
  • Free Hobby tier is genuinely usable — all product features free if you bring your own model access (ChatGPT/Claude subscription or API keys) and your own runners, with no token fees on your keys
  • No markup on model usage — paid credits are billed at providers’ list prices, and paused orbs cost nothing
  • Team-friendly without seat fees — Teams costs nothing extra, with shared billing, pooled credits, multiplayer thread sharing, SAML/OIDC SSO and Linear + GitLab integrations

❌ Cons

  • Pricing has changed several times in 2026 (ad-supported free tier paused, July subscriptions, September 13, 2026 restructure) — budget on a short horizon and re-check before subscribing
  • Native apps are macOS-only (macOS 26+) and iPhone/iPad (public TestFlight beta); Windows and Linux users work through the web app or CLI
  • Amp states it keeps no backward compatibility and removes features it doesn’t use, so workflows built on it can break without warning; the Amp service itself cannot be self-hosted (only orbs/runners can)

Frequently asked questions

Is Amp free?

Yes — Amp has a free Hobby tier ($0) with all product features if you bring your own model access. The entry paid plan is Individual (Megawatt) at $20 / month.

What is Amp best for?

Best for: small teams that want agents working in parallel on their own cloud machines — assign a Linear issue and review the fix later. Start free on Hobby with your own model subscription; Individual $20/mo adds hosted orb time.
