Overview

Most AI coding tools lock developers into one editor, one model vendor, and a fixed monthly seat price. Kilo Code is a free, open-source (MIT) agentic coding platform that runs inside the editors teams already use — VS Code, JetBrains, the terminal, the cloud, Slack, and mobile — and connects to 500+ AI models through one account, with bring-your-own-keys at provider rates and zero markup, so teams keep model choice, privacy, and cost control.

Official site: https://kilo.ai

Key Features

The capabilities that matter most for US teams:

  • Free, MIT-licensed agentic coding in VS Code, JetBrains, CLI and cloud
  • 500+ models via Kilo Gateway, BYOK at provider rates, or local models
  • Cloud Agents that keep working on GitHub and GitLab repos overnight
  • Four specialized agents: Code, Plan, Debug and Ask, with sub-agent delegation
  • Built-in MCP marketplace and repo indexing

✅ Pros

  • Free and MIT-licensed — the VS Code extension, JetBrains plugin, and CLI cost $0 for individuals, with no mandatory subscription
  • 500+ models through Kilo Gateway plus bring-your-own-keys at provider rates with zero markup, or fully local models via Ollama and LM Studio
  • Runs inside existing editors (VS Code, JetBrains, CLI) — no editor fork required — plus Cloud Agents that keep working on GitHub and GitLab repos after the laptop closes
  • Four specialized agents (Code, Plan, Debug, Ask) with sub-agent delegation, repo indexing, and a built-in MCP marketplace

❌ Cons

  • 'Free' is only the platform — inference and cloud compute are billed separately, and the real bill can surprise (5% processing fee on credit purchases, per-second cloud compute, paid credits expire after one calendar year)
  • Free hosted models may route prompts to providers that log them, per Kilo's own docs — a privacy caveat for sensitive code
  • Acquired by Anaconda in July 2026, with an enterprise-leaning direction that could change the free offering over time; Kilo Desktop is still in beta
  • Kilo's own pages disagree on user counts (5M+ developers vs 750K+ user base), so treat the '5M+ users' claim cautiously

Verified Pricing

Prices change — always check the official site before buying. Prices below are the widely published plans at time of writing. Prices exclude taxes. Inference is billed at provider rates with zero markup, plus a 5% processing fee on credit purchases (for example, $20 of credits costs $21; the fee is non-refundable even on refunded purchases). Cloud compute is billed per second (Code Review $0.33/hr, Cloud Agent Docker/Small $0.60/hr, Standard $1.20/hr) and paid credits expire one calendar year after purchase. Frequently asked questions

Is Kilo Code free?

Yes — the platform itself is free and open source (MIT): the VS Code extension, JetBrains plugin and CLI cost $0, with free models, bring-your-own-keys and local models. But inference and cloud compute are billed separately, so the real bill depends on the models and cloud time you use.

What is Kilo Code best for?

US teams that want model freedom and cost control: engineers using the free open-source agent in VS Code with their own Anthropic or OpenAI keys, teams running Cloud Agents overnight on GitHub repos, and health-tech or fintech teams running local models via Ollama so proprietary code never leaves their own machines.

What should I watch out for with Kilo Code?

The 5% processing fee on credit purchases, per-second cloud compute, and paid credits expiring after one calendar year can surprise you. Free hosted models may route prompts to providers that log them, and the July 2026 Anaconda acquisition could shift the free offering over time.

Verdict

Best for: US teams that want model freedom and cost control — engineers running the free open-source agent with their own keys, teams using overnight Cloud Agents, and regulated teams running local models so code never leaves their machines.
