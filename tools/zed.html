Overview

Most AI code editors are Electron-based VS Code forks that feel sluggish on large repos and lock you into one vendor’s models and billing. Zed is a from-scratch, Rust-native editor with a GPU-rendered interface built for speed, live collaboration, and AI agents — free forever, with hosted models optional and your own API keys always welcome.

Official site: https://zed.dev/

Key Features

The capabilities that matter most for US teams:

  • Blazing-fast Rust-native, GPU-rendered editor; noticeably quicker than Electron-based editors on large codebases
  • Free forever with bring-your-own-key freedom — use any Anthropic, OpenAI, Google, Bedrock, DeepSeek, Mistral, OpenRouter key, a ChatGPT/Claude/Copilot subscription, or local models via Ollama/LM Studio
  • Pro ($10/mo) unlocks Zed-hosted Claude, GPT, and Gemini models plus unlimited Zeta edit predictions
  • Runs multiple agent threads in parallel and connects external agents (Claude Agent, Codex, OpenCode) via the Agent Client Protocol; open source under GPL-3.0

❌ Cons

  • Hosted AI is metered: Pro includes only $5 of token credit per month, and heavy agent use bills at API list price +10%, so costs can climb fast
  • No cloud or web agent — it is a desktop editor only (macOS, Linux, Windows)
  • Business plan ($30/seat) has no SSO/SAML/SCIM yet and no bundled AI credit

Frequently asked questions

Is Zed free?

Yes — Zed has a free Personal plan ($0) forever: the full editor, with AI through your own API keys, an existing ChatGPT/Claude/Copilot subscription, local models, or external agents. The entry paid plan is Pro at $10 / month, which adds Zed-hosted models and unlimited Zeta edit predictions.

Best for: developers who want the fastest open-source code editor with optional hosted AI and complete freedom to bring their own models and keys.
