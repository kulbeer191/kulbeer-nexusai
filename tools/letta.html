Letta Review 2026

A stateful AI agent platform from the creators of MemGPT that gives agents persistent, self-editing memory — so the same agent remembers your codebase, your customers and what it learned last week instead of starting from zero every session.

Visit Official Site ↗   Feature your tool

Overview

Most AI agents are amnesiacs — every new session starts from zero, so long-running work loses context and repeats mistakes. Letta gives agents a persistent memory system (working memory, archival storage, recall) that agents edit themselves, so the same agent remembers codebase conventions, customers and past lessons — and gets better the longer it runs. It ships as an open-source framework (Apache 2.0) plus hosted Letta Cloud and Letta Code, a self-improving coding agent.

Official site: https://letta.com/

Key Features

The capabilities that matter most for US teams:

  • Persistent, self-editing agent memory (working memory, archival storage, recall)
  • Bring your own API keys across OpenAI, Claude and Gemini — no vendor lock-in
  • Letta Code coding agent with remote sandboxes and Slack/Telegram/Discord
  • Open-source framework (Apache 2.0) with a self-host path
  • Teams Pro shared agents with access permissions

✅ Pros

  • Unique memory-first architecture — agents with editable long-term memory, not a retrieval bolt-on; the MemGPT paper is the foundational work in this space
  • Truly model-agnostic — bring your own API keys, or use ChatGPT/Codex, Kimi or Z.AI coding plans; no vendor lock-in
  • Free tier is genuinely usable — 3 stateful agents with your own keys, no card required
  • Open source (Apache 2.0) and self-hostable — the core framework costs nothing to run yourself
  • Letta Code is a real shipping product — a memory-persistent coding agent with remote sandboxes, plus Slack/Telegram/Discord and a TypeScript SDK

❌ Cons

  • Developer-leaning — there is no true no-code builder for non-technical business users; this is a framework/API first
  • The free tier includes NO model usage — you pay for models yourself (own keys or bought credits), so '$0' is not the real cost of running agents
  • Real monthly cost scales fast — Letta's own guidance puts casual daily coding at ~$100+/month on pay-as-you-go model usage, and heavy users at $200+
  • Pricing changed recently (13 Nov 2026) — the usage-based API plan was removed from the pricing page, so many third-party guides still show stale tiers

Frequently asked questions

Is Letta free?

Yes. The Free plan costs $0 and includes 3 stateful agents with your own API keys and no card required — but it includes no model usage, so you pay for models yourself (own keys or bought credits). Paid plans start at Pro, $20 a month, which includes $20 a month in credits.

What is Letta best for?

US dev teams and startups that need agents with long-term memory — a coding agent that remembers codebase conventions and past bugs across weeks of work, or a customer-facing agent whose memory of each customer persists across conversations.

What should I watch out for with Letta?

The free tier includes no model usage, so '$0' is not the real cost of running agents, and pricing changed in November 2026 — guides showing the old API plan are stale.

Verdict

Best for: US dev teams that need agents with long-term memory — with the warning that the free tier includes no model usage, so the real monthly cost is the subscription plus whatever models consume.
