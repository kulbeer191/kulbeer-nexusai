Ellipsis Review 2026

A managed cloud platform where coding agents — Claude Code, Codex and Gemini — run on real repo work inside governed sandboxes, with scoped credentials, hard budget caps and a full audit trail, billed by usage instead of per seat.

Overview

Engineering orgs want coding agents running on real repo work — PR review, bug fixes, incident triage, dependency bumps — but not with developers' laptops and API keys as the blast radius. Ellipsis is a managed cloud platform where every agent is defined in code (YAML/Python/TypeScript) and runs in an isolated sandbox with scoped credentials, hard budget caps and a full audit trail, triggered from GitHub, Linear, Slack or cron.

Official site: https://ellipsis.dev

Key Features

The capabilities that matter most for US teams:

  • Governed sandboxes with scoped credentials and a full audit trail
  • Model-agnostic agent runtime (Claude Code, Codex, Gemini)
  • Triggers from GitHub, Linear, Slack, Sentry and cron
  • BYOC in your own AWS VPC with the full feature set
  • $0 per seat usage-based billing

✅ Pros

  • $0 per seat — the bill tracks usage, not headcount, which is rare in this category
  • Model-agnostic: runs Claude Code, Codex and Gemini through one API/SDK
  • Governed sandboxes: per-session scoped credentials, zero source retention, every command and file change logged
  • Triggers from GitHub, Linear, Slack, Sentry and cron — agents run without a human driving the session
  • BYOC option runs sandboxes inside your own AWS VPC with the full feature set
  • SOC 2 Type I certified (Type II in progress); session and fleet observability with spend tracking

❌ Cons

  • No permanent free plan — free access for open-source projects is case-by-case by email only
  • Usage-based billing makes the monthly cost unpredictable; a busy agent fleet can spike the token bill
  • Optional support packages start at $5,000/month — enterprise-only territory
  • The old install-and-forget PR review bot no longer exists; getting review now means writing and maintaining YAML agent definitions
  • Advanced support tier price is disputed across sources ($7,500 vs $10,000/mo)

Frequently asked questions

Is Ellipsis free?

No. There is no permanent free plan — Ellipsis is usage-based with $0 per seat, and new organizations get a one-time $100 signup credit (no card required). Open-source projects may get free access case-by-case by emailing the team.

What is Ellipsis best for?

An engineering org that wants governed coding agents on real repo work — a review agent on every push with a budget cap per session, or a Slack-triggered triage agent that reproduces a reported bug before a human picks it up.

What should I watch out for with Ellipsis?

Usage-based billing makes the monthly cost unpredictable, and the old $20/dev/mo PR review bot is gone — getting review now means writing and maintaining YAML agent definitions.

Verdict

Best for: Engineering orgs that want governed coding agents on real repo work with a full audit trail — with the warning that there is no permanent free plan and usage-based billing makes the monthly cost unpredictable.
