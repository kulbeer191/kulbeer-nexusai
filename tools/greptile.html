Overview

US engineering teams merging high PR volumes can't review everything carefully — diff-only reviewers miss cross-file bugs and drown reviewers in noise. Greptile indexes the whole repository into a graph and runs agents on every pull request, catching bugs that span files, enforcing the team's own rules written in plain English, and learning from the team's PR comments — and its new TREX agent actually runs the PR branch in a sandbox to catch the bugs that only show up at runtime.

Official site: https://greptile.com/

Key Features

The capabilities that matter most for US teams:

  • Full-repository graph indexing with cross-file bug detection
  • TREX sandbox agent that runs the PR branch to catch runtime-only bugs
  • Custom rules in plain English with learning from the team's PR comments
  • Unlimited developers and agents with org-wide shared credits, no seat fees
  • Knowledge Base MCP, cross-repo context, Jira/Linear/Notion and coding-agent integrations

✅ Pros

  • Full-codebase indexing (repository graph) — catches cross-file bugs, not just diff-level issues, with a v4 multi-hop agent (March 2026) that traces dependencies and git history
  • TREX runs the PR branch in a sandbox to catch runtime-only bugs — a genuinely different capability from diff reviewers
  • Custom rules in plain English plus continuous learning from the team's own PR comments — reviews adapt to the team's standards
  • No seat fees on the new pricing: unlimited developers and agents, credits shared org-wide; free Starter tier (50 credits a month) plus free access for qualified open-source projects and startup credits

❌ Cons

  • Pricing was restructured in November 2026 ($30/seat a month → $1/credit, no seat fees) — older guides still quote the $30/seat model, so buyers must read the live page
  • The credit meter is the real cost driver: a Base review is 1 credit ($1) but Plus is 3 and Apex is 10, and AI-generated PR velocity (Cursor, Claude Code, Kiro) inflates review counts fast
  • Reviews are billed per completed review, not per PR — a push or rebase can trigger another billable review
  • Review-only — no code generation or editing inside your editor; it complements a coding agent rather than replacing one

Frequently asked questions

Is Greptile free?

Yes. The Starter plan costs $0 with 50 free credits a month for 1 active developer and unlimited repositories. Qualified open-source projects are free, and pre-Series A startups get 500 free credits a month for 6 months.

What is Greptile best for?

Engineering teams merging high PR volumes that want every PR reviewed with full-repo context and custom rules enforced without adding reviewer headcount — especially teams already generating PRs with AI coding agents (Cursor, Claude Code, Kiro) that need a review layer to catch the bugs agents introduce at volume.

What should I watch out for with Greptile?

The credit meter: a Base review is 1 credit ($1) but Plus is 3 and Apex is 10, and AI-generated PR velocity inflates review counts fast. Reviews are billed per completed review, not per PR — a push or rebase can trigger another billable review.

Verdict

Best for: US engineering teams merging high PR volumes that want full-codebase review context with no seat fees — with the warning that the credit meter means AI-generated PR velocity can push costs well past the old flat $30/seat.
