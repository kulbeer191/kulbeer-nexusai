Hermes Agent Review 2026

Nous Research’s free, open-source, self-hosted agent with one persistent memory across Telegram, Discord, Slack, WhatsApp, Signal and email — that writes its own skills from problems it has already solved.

Overview

Teams want an autonomous assistant that remembers context across weeks and keeps getting better, without handing all their data to a closed SaaS. Hermes Agent is Nous Research’s free, open-source, self-hosted agent that runs on your machine or in the cloud, keeps one persistent memory across Telegram, Discord, Slack, WhatsApp, Signal and email, and automatically creates new skills from problems it has already solved.

Official site: https://hermes-agent.nousresearch.com

Key Features

The capabilities that matter most for US teams:

  • Free, open-source client (MIT license) — install it yourself and bring your own model provider, including free local models via Ollama
  • Persistent memory and self-improving skills — it learns your projects and auto-generates reusable skills, so recurring work gets faster over time
  • One agent, one memory, every surface — Telegram, Discord, Slack, WhatsApp, Signal, Email, and CLI, plus a desktop app for Windows and Linux
  • Real autonomy with guardrails — natural-language scheduling for unattended reports and briefings, isolated subagents for parallel work, and five sandboxing backends

❌ Cons

  • The useful hosted parts cost money — hosted tools (web search, browser, images, speech) and the Cloud agent require a paid Nous Portal plan; the free tier is free models only
  • Technical install — setup is a terminal curl script and a Nous Portal account, a real barrier for non-developers
  • Young, fast-changing product — Nous has not published a product launch date, and the usage-model wording has shifted, so confirm current limits on the official site

Frequently asked questions

Is Hermes Agent free?

Yes — Hermes Agent has a free plan ($0) with free models only. The entry paid plan is Plus at $20 / month, which adds paid models, hosted tools and one Cloud agent.

What is Hermes Agent best for?

Best for: research and ops teams that want a free, self-hosted agent with persistent memory across every chat app — and are comfortable with a terminal install. Start free with local models; Plus $20/mo adds hosted tools and Cloud hosting.
